    Connect it once.

    One address, added to your assistant as a connector, then a sign-in. There is nothing to install and nothing to configure afterwards.

    https://euroleague-analytics-mcp.fly.dev/mcp

    1. In Claude

      Settings, then Connectors, then Add custom connector. Paste the address and sign in with Google.

    2. In ChatGPT

      Settings, then Connectors, then Add. Paste the same address and sign in with Google.

    3. Anywhere else

      Any client that speaks MCP takes the same address over Streamable HTTP. Gemini, Cursor, Zed and the MCP Inspector are all known to work; the repository lists what has been tested against what.

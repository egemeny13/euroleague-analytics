Connect it once.

There is one address, and it is the whole of the setup. Any assistant that speaks MCP takes it — there is nothing to install, and nothing to configure afterwards.

https://euroleague-analytics-mcp.fly.dev/mcp

Verified — connected and answering

  1. Open Settings, then Connectors.
  2. Choose Add custom connector and paste the address above.
  3. Sign in with Google when Claude opens the sign-in window.
  4. Ask it something. Eleven tools appear under the connector's name.

In Claude Code instead:

claude mcp add --transport http euroleague https://euroleague-analytics-mcp.fly.dev/mcp

In review — submitted to the ChatGPT app directory on 2 September 2026

Once it is approved you will add it by name, with no address to paste. Until then it connects the developer way, and the server already speaks everything the Apps SDK asks for.

  1. Turn on Developer mode in Settings → Connectors.
  2. Choose Create, paste the address, and pick OAuth.
  3. Sign in with Google.

Verified — connected and answering, in both the CLI and Antigravity

  1. In the Gemini CLI, one command:
gemini mcp add euroleague https://euroleague-analytics-mcp.fly.dev/mcp
  1. In Antigravity: add the same address under MCP servers.
  2. Check it with gemini mcp list — it should report connected.

Expected from each client's published MCP specification — not yet run here

How it works.

One protocol connects your assistant to 732 games of basketball data in four quiet beats.

1

Your Prompt

You ask in natural language inside Claude, ChatGPT, Gemini, or your editor CLI.

"Which lineup played best in the 4th quarter?"
→
2

MCP Query

Your assistant invokes a specialized el_* tool over StreamableHTTP.

el_get_lineup_stats(team="ULK", min_poss=50)
→
3

Warehouse Engine

Supabase PostgreSQL queries derived tables built from validated play-by-play events.

SELECT * FROM lineup_summary WHERE ...
→
4

Verified Answer

You receive the answer qualified by sample size, possessions, and data provenance.

One Address

Connect it once.

There is one address, and it is the whole of the setup. Any assistant that speaks MCP takes it — nothing to install, and nothing to configure afterwards.

https://euroleague-analytics-mcp.fly.dev/mcp

Verified — connected and answering

  1. Open Settings → Connectors.
  2. Choose Add custom connector and paste the address above.
  3. Sign in with Google when Claude opens the sign-in window.
  4. Ask it something. Eleven tools appear under the connector's name.

In Claude Code CLI instead:

claude mcp add --transport http euroleague https://euroleague-analytics-mcp.fly.dev/mcp

In review — submitted to the ChatGPT app directory on 2 September 2026

Once approved you will add it by name without pasting an address. Until then, connect via Developer Mode:

  1. Turn on Developer mode in Settings → Connectors.
  2. Choose Create, paste the address, and pick OAuth.
  3. Sign in with Google.

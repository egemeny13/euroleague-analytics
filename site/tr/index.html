Claude — ücretsiz planda da çalışır

Ücretsiz hesaplar bir özel bağlayıcı ekleyebilir. Claude yardım merkezinden 7 Ekim 2026'da kontrol edildi.

  1. Customize'ı, ardından Connectors'ı aç.
  2. + Add'e, sonra Add custom connector'a tıkla.
  3. Adını EuroLeague Analytics koy, adresi yapıştır; Continue'ya, sonra Add'e tıkla.
  4. Claude isteyince Google ile giriş yap.
  5. Bir sohbette + → Connectors'ı açıp bağlayıcıyı etkinleştir.

Web'de, masaüstü uygulamasında ve telefonda çalışır. Claude Code'da:

claude mcp add --transport http euroleague https://euroleague-analytics-mcp.fly.dev/mcp

ChatGPT — ücretli planlarda, web'de

Özel bağlayıcılar için Developer mode gerekiyor. Menü adları birkaç kez değişti; 7 Ekim 2026'da kontrol edildi.

  1. Settings → Security and login'i aç, Developer mode'u etkinleştir.
  2. Settings → Plugins'e (bazı hesaplarda Apps & Connectors) gidip + ya da Create'e tıkla.
  3. Adını European Basketball Analytics koy, adresi yapıştır ve OAuth'u seç.
  4. Google ile giriş yap, sonra bir sohbette bağlayıcıyı aç.

Hangi sezonları sorabilirim?
